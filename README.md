## Hello there!

I am Frederick Katsura, a passionate, self-taught software engineer who loves going from designing to creating the next piece of software!

I have been building a variety of open source projects since I first started [MargarineBot](https://github.com/AurelicButter/MargarineBot) back in 2017. I focused solely on backend JavaScript work, since Discord served as the front-end interaction. Over time, these projects lead me to grow my own skill further:
- Documentation and NPM packages through [AniList-Node](https://github.com/AurelicButter/AniList-Node)
- Batch scripting through a [project template](https://github.com/AurelicButter/project-templates) repository
- Socket communications through Java in a [chatroom](https://github.com/AurelicButter/chatroom-java)
- Full-stack development with Angular/TypeScript/Express.js through [Myneworm](https://github.com/AurelicButter/Myneworm)

There has been plenty of opportunities to learn and expand my skills over the years that if you name it, I have probably tried it specifically or an alternative with the same purpose. The passion for software development for me is the driving force behind my craft and my expertise. For whatever the projects need from me, I'm always there, ready to create!

### Current Focuses
